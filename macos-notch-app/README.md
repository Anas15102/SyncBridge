## Overview

**SyncBridge** brings seamless, lightning-fast file sharing (AirDrop-style) and real-time clipboard synchronization between your macOS Dynamic Notch and your Android phone over your local Wi-Fi network.

---

## Features

- **Dynamic Notch Island:** Expands smoothly on mouse hover or file drag-and-drop right from your MacBook's top bezel.
- **Wi-Fi File Beaming (AirDrop):** Drag and drop any file (`.jpg`, `.png`, `.mp4`, `.mp3`, `.pdf`, `.zip`, `.dmg`, etc.) onto your screen notch to beam it directly to your Android phone's Downloads folder.
- **Live Clipboard Sync:** Automatically syncs copied text snippets instantly between Mac and Android.
- **KDE Connect Protocol Compatible:** Fully interoperable with standard KDE Connect / Soduto protocols.

---

## Installation & Running

### System Requirements
- macOS **14 Sonoma** or later
- Apple Silicon or Intel Mac

### Opening the App
1. Open **SyncBridge.app** from your project directory.
2. Grant local network permissions so your Mac and Android phone can discover each other.
3. Enjoy seamless cross-device synchronization!

---

## Building from Source

1. **Open the Project in Xcode**:
   ```bash
   open SyncBridge.xcodeproj
   ```
2. **Build and Run**:
   - Select the `SyncBridge` scheme and press `Cmd + R`.
